# 💡 Estructura de Datos en ML

> Pertenece a: **[[M01 - What is Machine Learning]]** | Lección de Origen: **[[06-Data Terminology]]**

---

### 📖 Definición Formal (Grounded)
Componentes fundamentales de un dataset: Instancias (filas/observaciones), Features (características/variables independientes X) y Target (etiqueta/variable dependiente Y).

---

### 🧠 Analogía Intuitiva (Patrón DeepTutor)
> Las features son los ingredientes y el target es el tipo de pastel resultante.

---

### 🎯 Regla de Decisión para Product Managers
> [!TIP]
> **Heurística de Producto:**
> Sin una definición clara y medible del Target (Y), ningún proyecto de ML puede tener éxito comercial.

---

### ⚠️ Error Conceptual Común (Misconception)
> [!WARNING]
> Pensar que más features siempre mejoran el modelo; el ruido en features irrelevantes degrada el rendimiento.
