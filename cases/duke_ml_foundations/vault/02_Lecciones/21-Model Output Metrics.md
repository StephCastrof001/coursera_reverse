# 21-Model Output Metrics

[00:04] Utilizamos las métricas de salida del modelo en varios puntos del proceso de modelado. En primer lugar, utilizamos las métricas de salida para comparar y evaluar los diferentes modelos que podríamos crear y hacer nuestra selección del modelo a utilizar. Una vez que hemos seleccionado nuestro modelo final, utilizamos las métricas de salida para evaluar el rendimiento de ese modelo en nuestro conjunto de datos de prueba antes de desplegarlo, y proporcionarlo a nuestros clientes.

[00:33] Por último, utilizaremos las métricas de salida de forma continua para evaluar el rendimiento continuo de nuestro modelo a medida que se utiliza en el mundo real. Cuando comparamos modelos, calculamos estas métricas de salida utilizando el conjunto de validación o la estrategia de validación cruzada como comentamos en el último módulo.

[00:56] Una vez que hemos seleccionado el modelo final que vamos a utilizar, aplicamos nuestro conjunto de prueba y calculamos una métrica de salida utilizando el conjunto de prueba para generar predicciones.
