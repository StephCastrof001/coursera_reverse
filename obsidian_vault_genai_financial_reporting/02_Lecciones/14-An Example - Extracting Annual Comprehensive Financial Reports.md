## 📜 Transcripción Curada

Hola a todos, bienvenidos de nuevo a nuestra conferencia. En la conferencia de hoy, analizaremos una aplicación real de este marco sobre los ACFR (Annual Comprehensive Financial Report). Ahora, echemos un vistazo a la aplicación real de este marco, extrayendo datos financieros de los informes financieros integrales anuales o ACFR (Annual Comprehensive Financial Report) del gobierno local de EE. UU. El desafío de los ACFR (Annual Comprehensive Financial Report) es que suelen ser documentos PDF extensos con un formato muy inconsistente que dificulta la extracción de datos manualmente o con métodos tradicionales. La solución consiste en aplicar nuestro marco compatible con la LLM para extraer las variables financieras clave, como los ingresos, los gastos y los saldos de los fondos, de manera coherente y automática. Nuestro objetivo es extraer estos datos con alta precisión y eficiencia, superando los problemas que plantea el formato incoherente. Este ejemplo demuestra claramente la eficacia del marco a la hora de gestionar documentos complejos y no estructurados en un escenario real, lo que demuestra su valor para automatizar la extracción de datos financieros. Estos son los pasos específicos que seguimos para extraer los datos financieros de los esfuerzos. En primer lugar, la conversión de datos. Usamos software para convertir los PDF en texto legible por máquina. Para las páginas escaneadas, aplicamos el OCR para capturar el texto con precisión. En segundo lugar, la comprensión del TOC o la comprensión de la tabla de contenido. El laboratorio de datos se utilizó para interpretar la tabla de contenido de cada documento, lo que nos ayudó a identificar las secciones que contienen los datos financieros que necesitábamos. En tercer lugar, ingeniería rápida. Diseñamos las instrucciones utilizando el aprendizaje mediante instrucciones e incluimos algunos ejemplos breves para guiar al laboratorio de datos a extraer la información deseada con precisión. En cuarto lugar, la consulta por lotes. Para gestionar varios esfuerzos de manera eficiente, los procesamos en lotes mediante la API de laboratorio de datos, lo que automatiza el proceso de extracción. Por último, la construcción de bases de datos. Almacenamos los datos extraídos en una base de datos relacional, organizándolos para facilitar el acceso y el análisis. Todo este proceso fue iterativo, lo que significa que refinamos las instrucciones y los métodos en función de los resultados de las consultas iniciales, mejorando la precisión y la eficiencia con cada pasada. Eso es todo para la conferencia de hoy. En la próxima lección, veremos otro ejemplo sobre los informes ESG (Environmental, Social, Governance). ¡Nos vemos allí!
